Practice the full certification exam, on infrastructure you control.

ilabhu provisions a full exam environment (CKA, CKAD, CKS, RHCSA, ...) in your own cloud account or on Linux servers you already own. Multi-domain, time-bounded, scored. No shared sandbox, no subscription.

Get started View on GitHub

BYO cloud or hosts

Run on AWS, GCP, Azure or DigitalOcean via short-lived assumed credentials, or hand ilabhu a list of Linux servers you already operate. Resources you own, billing you control, lifecycle you decide.

Exam-shaped

Each exam mirrors the real certification: weighted domains, ~15-20 tasks, time-bounded, scored against a passing threshold. Not a stack of disconnected micro-labs.

Self-hostable

Open source under Apache 2.0. Fork it, run it on your own machine, contribute exams. One Go binary plus a Next.js frontend.

How it works

An exam is a versioned directory under exams/ containing a manifest, one Terraform module per supported cloud provider, and (optionally) a setup script for the BYO-hosts adapter. 

## exams/cka/warmup/exam.yaml
schema_version: 1
id: cka/warmup
exam: CKA
title: CKA — Warmup
time_limit_minutes: 30
passing_score: 100

domains:
  - name: Workloads & Scheduling
    weight: 100

infrastructure:
  ttl_minutes: 120
  providers:
    aws:           { module: ./aws,           inputs: { region: eu-west-1,    instance_type: t3.small } }
    digitalocean:  { module: ./digitalocean,  inputs: { region: ams3,         droplet_size: s-1vcpu-2gb } }
    gcp:           { module: ./gcp,           inputs: { region: europe-west1, machine_type: e2-small } }
    azure:         { module: ./azure,         inputs: { location: westeurope, vm_size: Standard_B2s } }
    byo-hosts:     { setup_script: ./byo-hosts/setup.sh, roles: [{ name: node, count: 1 }] }

tasks:
  - id: create-pod
    title: Create the Pod
    domain: Workloads & Scheduling
    weight: 100
    instructions: |
      Create a Pod nginx-limited with CPU 200m, memory 256Mi.
    validations:
      - kind: kubectl
        args: ["get", "pod", "nginx-limited", "-o", "jsonpath={.status.phase}"]
        expect_equals: "Running"

Try it locally

cd ilabhu/control-plane && go run ./cmd/ilabhud -addr :8080 -exams-dir ../exams &
cd ../web && npm install && npm run dev

Then open http://localhost:3000.

Frequently asked

What is ilabhu?

ilabhu is an open-source, self-hostable certification exam simulator for cloud certifications like CKA, CKAD, CKS and RHCSA. It provisions the full exam environment — multi-domain, time-bounded, scored — in the user's own AWS, GCP, Azure or DigitalOcean account, or on Linux servers the user already operates.

Is ilabhu free?

Yes. ilabhu is licensed Apache 2.0 and there is no SaaS tier. You run the control plane yourself and pay your own infrastructure costs (~$0.04–$0.08 per two-hour cloud session), or nothing at all with the BYO-hosts adapter and a Linux server you already operate.

Which cloud providers are supported?

All five declared providers ship today: AWS (sts:AssumeRole + external id), DigitalOcean (Personal Access Token), Google Cloud (Service Account key), Azure (Service Principal with client secret) and BYO-hosts (your own Linux servers reachable over SSH).

How is ilabhu different from Killercoda or KodeKloud?

Killercoda and KodeKloud run on shared infrastructure under their own subscription. ilabhu is open source, runs in your account or on your hardware, and ships full exam-shaped simulations (~15–20 tasks, weighted domains, scored, time-bounded) instead of disconnected micro-labs.

Can I add my own exam?

Yes. An exam is a versioned directory under exams/ with an exam.yaml manifest (validated against a JSON Schema), one Terraform module per supported cloud provider, and an optional BYO-hosts setup script. See docs/authoring-an-exam.md.
